# ProjectPlan Schema

`ProjectPlan` is the main contract generated by Flowro and consumed by the Product Design Agent and Coding Agent.

## Required Shape

- `metadata`: product name, version, draft/approved status.
- `templateId`: approved base template. V1 supports `nextjs-app`.
- `appSummary`: concise product description.
- `targetUser`: primary audience.
- `problem`: problem the app solves.
- `successCriteria`: measurable outcomes for the generated app.
- `routes`: pages/screens with path, purpose, and primary actions.
- `dataModels`: product data entities and fields.
- `auth`: whether accounts are required and implementation notes.
- `integrations`: external systems required by the app.
- `uiRequirements`: design instructions passed to the Product Design Agent.
- `buildTasks`: implementation tasks used by the Coding Agent.
- `acceptanceChecks`: validation checklist before handoff.
- `risks`: known constraints or failure modes.

## Rules

- AI must choose from approved templates only.
- `templateId` must be `nextjs-app` in V1.
- The plan must be approved before UI generation.
- Legacy PRD projects can be transformed into a draft `ProjectPlan` for read compatibility.
